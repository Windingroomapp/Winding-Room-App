WINDING ROOM — GITHUB PAGES LEGAL SITE
========================================

FILES TO UPLOAD
---------------
Upload these four files to the ROOT of your GitHub repository:

1. index.html
2. privacy.html
3. terms.html
4. winding-room-logo.png

GITHUB PAGES SETUP
------------------
1. Open your "winding-room" repository on GitHub.
2. Add/upload all four files above to the repository root.
3. Open Settings.
4. Open Pages in the left sidebar.
5. Under "Build and deployment":
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
6. Click Save.
7. Wait for GitHub to publish the site.
